# biblioteca java
📚 Biblioteca Java

Projeto desenvolvido durante meus estudos de Java com foco em Programação Orientada a Objetos (POO).

Funcionalidades: 
Cadastro de livros, 
Listagem de livros, 
Empréstimo de exemplares, 
Devolução de livros,
Identificação do livro com mais exemplares, 
Relatório de livros com baixo estoque, 
Cálculo do total de exemplares, 
Conceitos praticados, 
Classes e Objetos, 
Construtores, 
Arrays de Objetos, 
Loops (for e while), 
Estruturas Condicionais, 
Encapsulamento (em evolução), 
Organização de código, 
Tecnologias, 
Java, 
Scanner, 
IDE NetBeans, 
Objetivo, 

Este projeto foi criado para consolidar os conhecimentos adquiridos durante os estudos do livro Use a Cabeça Java e servir como base para projetos maiores no futuro.
